# Getting help

1. **Read the docs:** the [User manual](docs/USER_MANUAL.md) and [Troubleshooting & FAQ](docs/TROUBLESHOOTING.md) answer most questions.
2. **Ask a question:** use [GitHub Discussions](https://github.com/YOUR-GITHUB-USERNAME/SRec/discussions) (Q&A category).
3. **Found a bug?** [Open a bug report](https://github.com/YOUR-GITHUB-USERNAME/SRec/issues/new/choose) with your Windows build, GPU and driver, the encoder shown in SRec's settings, and the log from `Videos\SRec Recordings\logs` if there is one.
4. **Security issue?** Follow [SECURITY.md](SECURITY.md). Please don't post it publicly.

SRec is a volunteer, open-source project. There's no paid support, but every good report helps make it better for everyone.
